# Fieldnote release notes

- 11-bin embodied AI research taxonomy.
- Static searchable paper atlas, opportunity lab, archive browser and deep-dive prompt builder.
- Bootstrap corpus: 12 curated papers, 6 research-opportunity hypotheses, and the initial 7-day archive snapshot dated 2026-11-07.
- Automated source ingestion: arXiv, OpenReview public records and OpenAlex discovery (aggregator entries remain flagged for verification).
- Daily GitHub Actions workflow: refresh index/archive, optional model-assisted idea generation, build and deploy GitHub Pages.
- The bootstrap dataset is a starting corpus, not a claim of exhaustive literature coverage. Run the workflow after publishing to obtain a fresh source scan.

See README.md for deployment, source coverage, limitations and optional API configuration.
