# Public discoverability

The repository is public. The build emits crawlable paper landing pages, canonical URLs, page descriptions, ScholarlyArticle JSON-LD, `robots.txt`, `sitemap.xml` and an Atom feed. These improve crawling and discovery but cannot guarantee indexing.

After deployment:
1. Add `https://hari-hashing.github.io/fieldnote/` as a URL-prefix property in Google Search Console.
2. Complete the ownership verification offered by Search Console.
3. Submit `https://hari-hashing.github.io/fieldnote/sitemap.xml`.
4. Optionally register the site with Bing Webmaster Tools and submit the same sitemap.
5. Check the sitemap report and URL inspection for crawl/canonical problems.

Keep the site public and do not add `noindex`. Search engines decide when and whether a public URL is indexed.
